## Shared Design DNA (all images)

### Layout
- Card-based UI with heavy border-radius
- Generous whitespace and padding
- Clear visual hierarchy (label → value → action)

### Components library emerging
- Feature / marketing cards
- Progress & goal trackers
- Analytics charts (line, gradient fill, tooltips)
- Monitoring with thresholds & alerts
- Segmented filters & dropdowns
- Status badges (active, saved, overheat, healthy)
- Tag pills (add/remove)
- Avatar + metadata rows
- File attachment rows
- Multi-step progress indicators
- Job/listing cards with dual CTAs
- Landing hero sections (nav + image + CTA)
- Kanban task cards (priority, assignee, progress ring)
- Ticket / pass cards (route timeline, QR, live countdown)
- Pastel job grid cards (carousel dots, color-coded blocks)
- Profile cards (banner + avatar overlap, stats row, action icons)

### Visual style
- Modern SaaS / fintech / health / corporate aesthetic
- Soft shadows, rounded corners
- Gradient accents (blue, red/maroon, multi-color charts, purple)
- Clean sans-serif typography (serif used sparingly for emphasis)
- Color-coded status (green = ok, red/orange = warning/priority)
- Pastel block backgrounds for card differentiation
- Dashed dividers for section separation
- Route/timeline connectors (dots + dashed lines)

### Interaction patterns
- Hover tooltips on charts
- Toggle states (Save ↔ Saved, tab filters)
- Primary + secondary buttons
- Progress bars with percentage labels
- Story/carousel step indicators
- QR code display with expand hint
- Live countdown timers
- Circular progress rings
- Verified badges on profiles
- Bookmark/save toggle on listings
